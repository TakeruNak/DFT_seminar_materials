**ねらい**：微分方程式を計算機で扱うには、関数を基底で展開して行列問題に変換する必要がある。
その際に効いてくる 3 つの性質——**完備性 / 直交性 / 境界条件**——を手を動かして確認する。

```
-½∇²φ(r) + V(r)φ(r) = εφ(r)        φ(r) = Σ cᵢ gᵢ(r)
          ↓  基底展開
     H c = ε c                      （行列の固有値問題 → 計算機で解ける）
```

## 演習 03: 矩形波を sin で展開する

**ディレクトリ**: [`03_sinx_fitting/`](../../03_sinx_fitting/)

### 内容

矩形波 `y = sign(sin x)` を、奇数次の sin 関数の重ね合わせで近似する。

```
f(x) ≈ Σ_{k=1}^{N} (4/π) · sin((2k-1)x) / (2k-1)
```

### 実行

```bash
cd 03_sinx_fitting
source ../.venv/bin/activate
python fourier.py
```

初期状態は `N_list = [1]`（基底 1 本）。グラフウィンドウが開く。

### 課題

1. `N_list` を `[1]` → `[1, 3, 5, 10, 50]` のように増やし、`plt.subplot(1, 1, i+1)` を
   `plt.subplot(len(N_list), 1, i+1)` に直して並べて比較する
2. 基底を増やすと不連続点の近くに残る振動（**Gibbs 現象**）を観察する
3. 展開区間 `[-π, π]` の外側ではどうなるか、`x = np.linspace(-3*np.pi, 3*np.pi, 1000)` に
   変えて確認する

### 確認事項

- [ ] 基底を増やすほど近似が良くなること（完備性）を確認した
- [ ] 周期基底で展開した結果が、区間外で**周期的に繰り返す**ことを確認した
- [ ] 非周期関数を周期基底で展開したときに何が起きるか説明できる

> この性質が、第一原理計算で **周期境界条件 / 真空層** が重要になる理由につながる。

## 演習 04: 奇関数を偶関数基底で展開する

**ディレクトリ**: [`04_sinx-cosx/`](../../04_sinx-cosx/)

### 内容

奇関数 `sin(x)` を、**cos 基底のみ** で展開しようと試みる。

```
奇関数  f(x) = -f(-x)       例: sin(x)
偶関数  g(x) =  g(-x)       例: cos(kx)

係数    a_k = ∫ f(x)·cos(kx) dx / 正規化     ← 内積（射影）
```

### 実行

```bash
cd 04_sinx-cosx
python odd-by-even-rep.py
```

標準出力に係数 `a_0 ... a_N` が、グラフに元関数と近似結果が表示される。

### 課題

1. 出力された係数 `a_k` の値を確認する（何が起きているか）
2. `N = 10` を `N = 100` に増やしても結果が改善しないことを確認する
3. sin 基底を足せば表せることを確認する（`.answear/odd-by-full-rep.py` に完全形の例）

### 確認事項

- [ ] cos 基底だけでは sin を表せないことを、係数の値から説明できる
- [ ] 「基底系が完備でない」とはどういう状態か説明できる
- [ ] 三原色の例（Red + Blue だけでは全色を作れない）と対応づけられる

## 演習 05: Gaussian を平面波基底で展開する

**ディレクトリ**: [`05_gaussian-plane-wave-fitting/`](../../05_gaussian-plane-wave-fitting/)

原子核まわりに局在した電子軌道を模した Gaussian を、**平面波基底**で展開する。
Quantum ESPRESSO が使う基底そのもの。

### 平面波基底と cutoff energy

```
-½∇² φ(x) = ε φ(x)        →   φ_m(x) = exp( i·2πm·x / L ),  m ∈ ℤ

各平面波が持つ運動エネルギー   ε_m = ½ · (2πm/L)²
cutoff energy E_cut まで採用   →  |m| ≤ L·√(2E_cut) / 2π
```

**E_cut を上げる = より高周波の基底を取り込む = 急峻な構造を表せる。**

### 05-A: one-shot（1 つの E_cut で見る）

```bash
cd 05_gaussian-plane-wave-fitting/one-shot
python wf-fitting.py
```

標準出力に `Energy cutoff / k_max / n_max` と相対誤差 (RSE) が出る。

| 変数 | 既定値 | 意味 |
|---|---|---|
| `E_list` | `[20]` | 試す cutoff energy |
| `L` | 20.0 | 箱の半幅（周期長は 2L） |
| `N` | 400 | 実空間グリッド点数 |
| `gaussian()` | 2 つの Gaussian の和 | 対象関数 |

**課題**: `E_list = [20]` を `[0.5]`, `[2]`, `[50]` と変えて、基底本数 `n_max` と
再現性の関係を見る。

### 05-B: convergence（cutoff 依存性を一度に見る）

```bash
cd 05_gaussian-plane-wave-fitting/convergence
python wf-fitting.py
```

出力:

| ファイル | 内容 |
|---|---|
| `convergence_wave.png` | 各 E_cut での再現波形の重ね書き |
| `convergence.png` | 相対誤差 (RSE) vs E_cut（対数軸） |

既定の `E_list = [0.5, 1, 2, 5, 10, 20]`。

### 課題

1. `convergence.png` から、誤差が実用水準まで落ちる E_cut を読み取る
2. Gaussian の幅 `sigma` を 1.0 → 0.3 と**狭く**して再実行し、必要な E_cut が
   どう変わるか確認する
3. スクリプト内にコメントアウトされている 2 つ山の関数（`def wf(x)`）を有効にして
   同じ検討をする

### 確認事項

- [ ] cutoff energy を上げることが「高周波の基底を足すこと」だと説明できる
- [ ] 局在した関数ほど高い cutoff が必要な理由を説明できる
- [ ] 内殻電子をそのまま平面波で表すのが非現実的な理由（→ **擬ポテンシャル**）を説明できる
