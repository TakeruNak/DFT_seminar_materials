**目标**：要用计算机处理微分方程，必须把函数用基函数展开，转化为矩阵问题。
本章通过动手确认此时起关键作用的三个性质——**完备性 / 正交性 / 边界条件**。

```
-½∇²φ(r) + V(r)φ(r) = εφ(r)        φ(r) = Σ cᵢ gᵢ(r)
          ↓  基函数展开
     H c = ε c                      （矩阵本征值问题 → 计算机可解）
```

## 练习 03：用 sin 展开方波

**目录**：[`03_sinx_fitting/`](../../03_sinx_fitting/)

### 内容

用奇数阶正弦函数的叠加来近似方波 `y = sign(sin x)`。

```
f(x) ≈ Σ_{k=1}^{N} (4/π) · sin((2k-1)x) / (2k-1)
```

### 运行

```bash
cd 03_sinx_fitting
source ../.venv/bin/activate

```

## 练习 04：用偶函数基展开奇函数

**目录**：[`04_sinx-cosx/`](../../04_sinx-cosx/)

### 内容

尝试 **只用 cos 基** 来展开奇函数 `sin(x)`。

```
奇函数  f(x) = -f(-x)       例: sin(x)
偶函数  g(x) =  g(-x)       例: cos(kx)

系数    a_k = ∫ f(x)·cos(kx) dx / 归一化因子     ← 内积（投影）
```

### 运行

```bash
cd 04_sinx-cosx
python odd-by-even-rep.py
```

标准输出给出系数 `a_0 … a_N`，图中显示原函数与近似结果。

### 任务

1. 查看输出的系数 `a_k` 的数值（发生了什么？）
2. 确认把 `N = 10` 增大到 `N = 100` 也不会改善结果
3. 确认加入 sin 基后就能表示
   （完整版示例见 `.answear/odd-by-full-rep.py`）

## 练习 05：用平面波基展开高斯函数

**目录**：[`05_gaussian-plane-wave-fitting/`](../../05_gaussian-plane-wave-fitting/)

把模拟原子核周围局域电子轨道的高斯函数，用 **平面波基** 展开。
这正是 Quantum ESPRESSO 所使用的基。

### 平面波基与截断能

```
-½∇² φ(x) = ε φ(x)        →   φ_m(x) = exp( i·2πm·x / L ),  m ∈ ℤ

各平面波的动能               ε_m = ½ · (2πm/L)²
保留到截断能 E_cut 为止      →  |m| ≤ L·√(2E_cut) / 2π
```

**提高 E_cut = 引入更高频率的基 = 能够描述更陡峭的结构。**

### 05-A：one-shot（单一 E_cut）

```bash
cd 05_gaussian-plane-wave-fitting/one-shot
python wf-fitting.py
```

标准输出给出 `Energy cutoff / k_max / n_max` 和相对误差 (RSE)。

| 变量 | 默认值 | 含义 |
|---|---|---|
| `E_list` | `[20]` | 要尝试的截断能 |
| `L` | 20.0 | 盒子半宽（周期长度为 2L） |
| `N` | 400 | 实空间网格点数 |
| `gaussian()` | 两个高斯之和 | 目标函数 |

**任务**：把 `E_list = [20]` 改为 `[0.5]`, `[2]`, `[50]`，观察基函数个数
`n_max` 与重现程度之间的关系。

### 05-B：convergence（一次性查看截断能依赖性）

```bash
cd 05_gaussian-plane-wave-fitting/convergence
python wf-fitting.py
```

输出：

| 文件 | 内容 |
|---|---|
| `convergence_wave.png` | 各 E_cut 下重现波形的叠加图 |
| `convergence.png` | 相对误差 (RSE) 随 E_cut 的变化（对数坐标） |

默认 `E_list = [0.5, 1, 2, 5, 10, 20]`。

### 任务

1. 从 `convergence.png` 读出误差降到实用水平所需的 E_cut
2. 把高斯宽度 `sigma` 从 1.0 **收窄** 到 0.3 后重新运行，确认所需 E_cut 的变化
3. 启用脚本中被注释掉的双峰函数（`def wf(x)`），重复同样的研究

### 自查清单

- [ ] 能说明提高截断能就是"增加高频基函数"
- [ ] 能说明为什么越局域的函数需要越高的截断能
