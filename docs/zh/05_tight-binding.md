## 5-1. 模型

用 A/B 两个子晶格上的最近邻紧束缚来描述 graphene 的 π 电子体系。

```
晶格矢量     a₁ = (1, 0),  a₂ = (-1/2, √3/2)
轨道位置     A = (0, 0),  B = (1/3, 2/3)      （分数坐标）
跃迁积分     t = -2.8 eV  （最近邻 A–B 之间，共 3 条）
```

这就是练习 01 的 2×2 矩阵在 k 空间中的形式：

```
H(k) = |  0      f(k)  |        f(k) = t · Σ_δ exp(i k·δ)
       | f*(k)    0    |
```

在 K 点处 f(k) = 0，于是出现 **狄拉克锥（Dirac cone）**。

## 5-2. 运行

```bash
cd TB_model/graphene/src
source ../../../.venv/bin/activate
pip install pythtb pymatgen       # 若尚未安装
python test.py
```

> `test.py` 才是实际运行的脚本；`graphene.py` 只是模板（仅有 import）。
> `pythtb` 需要 **2.0 以上**（使用 `TBModel` / `Lattice` API）。
> `pymatgen` 仅在被注释掉的 CIF 导出部分用到，但由于被 import，必须安装。

**已验证**（pythtb 2.0.0 / 耗时约 10 秒）

| 项目 | 数值 |
|---|---|
| 带宽 | 约 17 eV ≈ 6\|t\| = 16.8 eV |
| K 点 | 两条能带在 0 eV 处简并（**狄拉克点**） |
| PDOS(A) 与 PDOS(B) | 完全一致 |

### 输出

| 文件 | 内容 |
|---|---|
| `graphene_tb.png` | 左：能带结构 (K′–Γ–K–M–Γ) / 右：DOS 与子晶格分解的 PDOS |

计算内容：

1. **能带结构** — 沿 `path = [K′, Γ, K, M, Γ]` 取 300 个点采样
2. **DOS / PDOS** — 在布里渊区取 120×120 网格，用高斯展宽（σ = 0.10 eV）
   构造态密度，再用本征矢的 A/B 分量 |c_A|²、|c_B|² 进行分解

## 5-3. 可调参数

| 变量 | 默认值 | 含义 |
|---|---|---|
| `t` | -2.8 | 最近邻跃迁积分 (eV) |
| `path`, `labels` | K′–Γ–K–M–Γ | 能带路径 |
| `nk_path` | 300 | 路径上的 k 点数 |
| `nk_grid` | 120 | DOS 用的布里渊区网格（120×120） |
| `sigma` | 0.10 | DOS 的高斯展宽 (eV) |
| `E_mesh` | -9 至 9 eV | DOS 的能量范围 |

## 5-4. 任务

1. 确认能带在 K 点处简并（狄拉克点）
2. 把 `sigma` 取为 0.02 / 0.10 / 0.5，比较 DOS 中范霍夫奇点的呈现方式
3. 把 `nk_grid` 取为 30 / 60 / 120，观察 DOS 的光滑程度如何变化
   （→ 与 03-6 中 DOS 的 k 点收敛是同一个问题）
4. 用子晶格的对称性说明为什么 A 与 B 的 PDOS 完全一致
5. **引入格点能**：给 A 和 B 不同的格点能（±Δ），能带会如何变化？
   这在物理上对应什么？（联想 h-BN）
